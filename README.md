# Leverantörsreskontra (branch `leverantorsreskontra`)

This branch is the standalone **Leverantörsreskontra** app — a Swedish
accounts-payable subledger. The application lives in:

    leverantorsreskontra/

See [`leverantorsreskontra/README.md`](leverantorsreskontra/README.md) for the
app, the Swedish-standards roadmap, and how to run it.

## Provenance

Seeded from the KASE invoice-capture demo. That demo is preserved unchanged on
`master` and at the tag **`kase-demo`**:

    git checkout kase-demo               # run the original demo
    git checkout leverantorsreskontra    # this app
